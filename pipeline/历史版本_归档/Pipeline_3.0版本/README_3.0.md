### 对于AI使用者

**Step 1**: 读取核心规则
```
优先阅读：财小析_Pipeline_3.0_完整规则手册.md
重点关注：数据口径规则、地区差异化处理、Section 2标准
```

**Step 2**: 识别公司地区
```python
# 地区识别逻辑
if currency == "CNY" and language == "中文":
    region = "中国A股"
    multiplier = "Thousands"
elif currency == "USD" and language == "英文":
    region = "美国"
    multiplier = "Millions"
elif currency == "RM" and language == "英文":
    region = "新加坡/马来西亚"
    multiplier = "Millions"
```

**Step 3**: 应用核心规则
```
✅ 使用合并净利润（含少数股东）
✅ 使用所有者权益合计（含少数股东）
✅ 严格按官方CSV公式计算财务指标
✅ 使用标准表格格式（包含Multiplier+Currency列）
```

## 🌍 支持的地区和特征

### 中国A股公司
```yaml
特征:
  - 货币: CNY (人民币)
  - 会计准则: 中国企业会计准则
  - Multiplier: Thousands (千元)
  - 表头: "公司全称2024年年度报告"
关键处理:
  - 净利润: 使用"五、净利润"（合并口径）
  - 避免: "归属于上市公司股东的净利润"
```

### 美国公司
```yaml
特征:
  - 货币: USD (美元)
  - 会计准则: US GAAP
  - Multiplier: Millions (百万美元)
  - 表头: "2024 Report"
关键处理:
  - 净利润: "Net income attributable to [Company]"
  - 股东权益: "[Company] shareholders' equity"
```

### 新加坡/马来西亚公司
```yaml
特征:
  - 货币: RM (马来西亚林吉特)
  - 会计准则: MFRS (基于IFRS)
  - Multiplier: Millions (百万林吉特)
  - 表头: "2024 Report"
关键处理:
  - 净利润: PATMI (Profit After Tax and Minority Interest)
```

### 英国公司
```yaml
特征:
  - 货币: GBP (英镑)
  - 会计准则: IFRS
  - Multiplier: Millions (百万英镑)
  - 表头: "2024 Report"
关键处理:
  - 服务业COGS可能为N/A
```

## 📊 质量保证体系

### 三重验证机制

1. **数据口径验证**
   - 合并净利润 vs 归母净利润
   - 合并权益 vs 归母权益
   - 口径一致性检查

2. **计算准确性验证**
   - 12项财务指标公式验证
   - 百分比格式检查
   - 数值合理性检查

3. **格式规范性验证**
   - 表格格式标准化
   - Multiplier+Currency列完整性
   - 内容结构完整性

### 质量检查清单

**Section 2 重点检查**：
- [ ] 财务表格包含Multiplier和Currency列
- [ ] S2.4使用百分比格式
- [ ] 财务指标计算正确
- [ ] 数据口径统一

- [ ] 表格markdown格式正确
- [ ] 表头符合地区标准
