## 📊 财小析 Pipeline 2.1核心特点

### 口径准确性（官方验证）

| 数据项 | 财小析2.1口径 | 验证来源 |
|--------|-------------|---------|
| **Net Profit** | 合并净利润（含少数股东损益）| sample003实证 ✅ |
| **Shareholders' Equity** | 所有者权益合计（含少数股东）| sample003实证 ✅ |
| Interest Expense | 利息费用（非财务费用）| 官方CSV ✅ |
| Dividends | 实际支付额（权益变动表）| 样本集标准 ✅ |

### 计算准确性

- ✅ 12项财务指标严格按官方CSV公式
- ✅ 全部使用百分比格式（非倍数）
- ✅ 恒等校验：Total Assets = Total E+L
- ✅ 计算误差<0.01%

### 格式规范性

- ✅ 中文公司表头："公司全称YYYY年年度报告"
- ✅ S5.2简短表头："2024 Report"
- ✅ 千分位逗号、负数"-"、N/A规范使用
- ✅ Multiplier: Thousands（禁止Units）
