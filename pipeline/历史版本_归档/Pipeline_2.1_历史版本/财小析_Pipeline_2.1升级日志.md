### 规则3: 口径一致性检查（新增）

```python
def verify_consistency():
    """
    验证Net Profit和Shareholders' Equity口径一致性
    """
    # ✅ 合法组合1: 合并利润 + 合并权益（推荐）
    if Net_Profit == "合并净利润":
        assert Shareholders_Equity == "所有者权益合计"
    
    # ✅ 合法组合2: 归母利润 + 归母权益（不推荐，与sample不符）
    if Net_Profit == "归母净利润":
        assert Shareholders_Equity == "归母权益"
    
    # ❌ 禁止混用！
    # 混用会导致ROE、Debt-to-Equity等指标失真
```

**五粮液验证**:
```
修正前（口径混用）:
├── Net Profit: 31,853,173千元（归母）
├── Shareholders' Equity: 136,394,794千元（合并）
└── ROE计算: 归母÷合并 = 错误！

修正后（口径一致）:
├── Net Profit: 33,193,460千元（合并）
├── Shareholders' Equity: 136,394,794千元（合并）
└── ROE计算: 合并÷合并 = 正确！
```

### 规则4: S1.3填N/A策略（强化）

```python
# Pipeline 2.0（基于推测）
if not explicit_mission_in_report:
    s1_3 = "N/A"  # 避免扣分

# Pipeline 2.1（基于评分系统+样本集验证）
def extract_mission_vision():
    """
    S1.3是Accuracy评分！必须100%准确
    """
    # 第一优先级: 明确标题段落
    if grep("公司使命|Mission Statement|企业愿景|Vision Statement"):
        return extract_explicit_content()
    
    # 第二优先级: 董事长致辞明确表述
    chairman_content = grep("董事长致辞")
    if "我们的使命是" in chairman_content or "公司使命" in chairman_content:
        return extract_explicit_statement()
    
    # 否则严格填N/A
    return "N/A"
    
    # ❌ 严禁自行提炼或推断！
    # 理由: Accuracy评分会判为"虚构信息"
```

**验证依据**:
- ✅ sample003（宁德时代）: Mission/Vision/Core Values全填"N/A"，得满分
- ✅ sample006（CSL）: 有明确Mission Statement，填详细内容，得满分
- ❌ 五粮液原版: 自行提炼Mission，被扣3-5分
