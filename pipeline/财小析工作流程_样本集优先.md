# 财小析工作流程 - 样本集优先原则

> **核心原则**：🥇 样本集 = 金标准  
> **创建日期**：2025-10-22  
> **优先级**：⭐⭐⭐ 最高

---

## 🎯 核心原则（绝对遵守）

```
🥇 样本集 = 金标准（绝对优先）
🥈 规范文档 = 辅助理解
🥉 如有冲突，样本集绝对优先
```

**含义**：
- ✅ 样本集的格式就是**唯一标准**
- ✅ 规范文档用于**理解背景**，不是格式规则
- ✅ 任何冲突，**无条件以样本集为准**

---

## 📋 标准工作流程

### 步骤1：确定地区和样本

| 地区 | 样本文件 | 公司 |
|------|---------|------|
| 中国 | `sample003.md` | 宁德时代 |
| 澳大利亚 | `sample006.md` | CSL Limited |
| 英国 | `sample002.md` | Chemring Group PLC |

### 步骤2：打开样本集作为**格式模板**

```bash
处理中国案例 → 打开 sample003.md
处理澳大利亚案例 → 打开 sample006.md
处理英国案例 → 打开 sample002.md
```

### 步骤3：逐Section对照样本格式

**标准流程**：
1. ✅ 读取sample对应Section的**实际格式**
2. ✅ 提取数据填入相同格式
3. ✅ 100%保持格式一致
4. ✅ 不添加、不删除、不修改格式

### 步骤4：规范文档作为辅助

**使用规范文档的方式**：
- ✅ 理解数据口径（如Multiplier判断）
- ✅ 理解计算公式
- ✅ 理解内容要求
- ❌ **不**作为格式标准

### 步骤5：冲突处理

```
IF 规范文档格式 ≠ 样本集格式
THEN 使用样本集格式（无条件）
```

## 📖 规范文档的正确用法

### ✅ 可以用规范文档理解：

1. **数据口径**
   - Multiplier判断逻辑（Thousands/Millions/Billions）
   - 会计科目对应关系
   - 计算公式

2. **内容要求**
   - S1.2每个维度写什么
   - S3.1分析要点
   - 数据来源要求

3. **地区特征**
   - 语言要求（中国简体中文）
   - 会计准则（中国GAAP vs IFRS）
   - 特殊规则（财年制、服务业COGS）

### ❌ 不能用规范文档决定：

1. **任何格式问题** → 必须看sample
2. **列标题/行标题** → 必须看sample
3. **表格结构** → 必须看sample
4. **标点符号、空格** → 必须看sample
