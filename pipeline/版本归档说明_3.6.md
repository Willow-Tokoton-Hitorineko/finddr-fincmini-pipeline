## 🔄 归档操作步骤

### 方式1：手动归档（推荐）

1. **创建目录**：
   - 在 `历史版本_归档/` 下创建 `Pipeline_3.5版本/` 文件夹

2. **移动文件**：
   - 将上述7个3.5版本文件移动到新建的文件夹中
   - 使用文件管理器拖拽或剪切粘贴

3. **验证**：
   - 确认根目录只保留3.6版本文件
   - 确认归档文件夹中有完整的7个文件

### 方式2：使用PowerShell脚本

```powershell
# 在规则库根目录执行
$source = "<规则库根目录>"  # 本地路径请自行替换
$dest = "$source\历史版本_归档\Pipeline_3.5版本"

# 创建目标目录
New-Item -ItemType Directory -Path $dest -Force

# 移动文件
$files = @(
    "AI快速使用指南_3.5.md",
    "Pipeline_3.5_使用说明.md",
    "README_3.5.md",
    "财小析_Pipeline_3.5_核心规则.md",
    "失败分析_3.5.md",
    "版本升级日志_3.5.md",
    "语言使用规则补充说明_3.5.md"
)

foreach ($file in $files) {
    Move-Item -Path "$source\$file" -Destination "$dest\$file" -Force
}

Write-Host "归档完成！已移动 $($files.Count) 个文件"
```
