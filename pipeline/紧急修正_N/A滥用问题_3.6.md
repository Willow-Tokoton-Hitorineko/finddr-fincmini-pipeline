## 🔴 绝对禁止的N/A滥用行为

### Section 2.1: Income Statement

**禁止填N/A的字段**（中国A股）：
1. ✅ Revenue - 必填（营业收入）
2. ✅ Cost of Goods Sold - 必填（营业成本）
3. ✅ Gross Profit - 必填（毛利润 = 营业收入 - 营业成本）
4. ✅ Operating Expense - 必填（期间费用合计 = 销售费用 + 管理费用 + 研发费用 + 财务费用）
5. ✅ Operating income - 必填（营业利润）
6. ✅ Net Profit - 必填（净利润，合并口径）
7. ✅ Income before income taxes - 必填（利润总额）
8. ✅ Income tax expense - 必填（所得税费用）
9. ✅ Interest Expense - 必填（财务费用中的利息支出）

**唯一允许N/A的情况**：
- 纯服务业的COGS和Gross Profit（如咨询公司、软件公司）
- 年报确实未单独披露的细分项目（极少见）

### Section 2.2: Balance Sheet

**禁止填N/A的字段**（中国A股）：
1. ✅ Total Assets - 必填（资产总计）
2. ✅ Current Assets - 必填（流动资产合计）
3. ✅ Non-Current Assets - 必填（非流动资产合计）
4. ✅ Total Liabilities - 必填（负债合计）
5. ✅ Current Liabilities - 必填（流动负债合计）
6. ✅ Non-Current Liabilities - 必填（非流动负债合计）
7. ✅ Shareholders' Equity - 必填（所有者权益合计，合并口径）
8. ✅ Retained Earnings - 必填（未分配利润）
9. ✅ Total Equity and Liabilities - 必填（负债和所有者权益总计）
10. ✅ Inventories - 必填（存货）
11. ✅ Prepaid Expenses - 必填（预付款项）

### Section 2.3: Cash Flow Statement

**禁止填N/A的字段**（中国A股）：
1. ✅ Net Cash Flow from Operations - 必填（经营活动产生的现金流量净额）
2. ✅ Net Cash Flow from Investing - 必填（投资活动产生的现金流量净额）
3. ✅ Net Cash Flow from Financing - 必填（筹资活动产生的现金流量净额）
4. ✅ Net Increase/Decrease in Cash - 必填（现金及现金等价物净增加额）
5. ✅ Dividends - 必填（分配股利、利润或偿付利息支付的现金）

## 正确的数据提取流程

### Step 1: 定位财务报表

**中国A股年报结构**：
```
第十节 财务报告
  ├── 一、审计报告
  ├── 二、财务报表
  │   ├── 1. 合并资产负债表
  │   ├── 2. 母公司资产负债表
  │   ├── 3. 合并利润表
  │   ├── 4. 母公司利润表
  │   ├── 5. 合并现金流量表
  │   └── 6. 母公司现金流量表
  └── 三、财务报表附注
```

**关键提示**：
- 使用**合并报表**（Consolidated），不用母公司报表
- 表格通常在年报的最后部分（第十节）
- 搜索关键词："合并资产负债表"、"合并利润表"、"合并现金流量表"

### Step 2: 精确提取数据

**利润表提取示例**（益海嘉里2024）：
```
合并利润表
单位：千元

项目                          2024年        2023年        2022年
一、营业总收入              238,866,319   251,523,736   257,485,444
    其中：营业收入          238,866,319   251,523,736   257,485,444
二、营业总成本              235,210,569   248,108,951   253,447,806
    其中：营业成本          ？？？        ？？？        ？？？
          销售费用          ？？？        ？？？        ？？？
          管理费用          ？？？        ？？？        ？？？
          研发费用          ？？？        ？？？        ？？？
          财务费用          ？？？        ？？？        ？？？
三、营业利润                ？？？        ？？？        ？？？
四、利润总额                3,655,750     3,414,785     4,037,638
五、净利润                  3,072,076     3,415,436     3,552,806
    所得税费用              583,674       -651          484,832
```

**提取规则**：
1. Revenue = 营业收入（第一行）
2. COGS = 营业成本（在营业总成本下）
3. Gross Profit = Revenue - COGS
4. Operating Expense = 销售费用 + 管理费用 + 研发费用 + 财务费用
5. Operating Income = 营业利润
6. Net Profit = 净利润（合并口径，包含少数股东损益）
7. Income Before Tax = 利润总额
8. Tax Expense = 所得税费用

### Step 3: 验证数据合理性

**必须通过的验证**：
```python
# 验证1：基本等式
assert Gross_Profit == Revenue - COGS
assert Net_Profit == Income_Before_Tax - Tax_Expense

# 验证2：合理性检查
assert 0 < COGS < Revenue  # 制造业
assert 0 < Net_Profit < Revenue  # 盈利企业
assert Current_Assets + Non_Current_Assets == Total_Assets
assert Total_Liabilities + Shareholders_Equity == Total_Assets

# 验证3：三年趋势合理
assert abs(Revenue_2024 / Revenue_2023 - 1) < 0.5  # 增长率<50%
```

## 问题2：格式细节不匹配

### 错误1：Section标题格式

**错误**：
```markdown
## S1.2: Core Competencies
## S1.3: Mission & Vision
```

**正确**（sample003格式）：
```markdown
## S1.2 : Core Competencies
## S1.3 : Mission & Vision
```

**规则**：冒号前必须有空格（中国地区特有）

### 错误2：N/A vs N.A

**错误**：
```markdown
| Mission Statement | N/A |
| Vision Statement | N/A |
| Core Values | N/A |
```

**正确**（sample003格式）：
```markdown
| Mission Statement | N.A |
| Vision Statement | N.A |
| Core Values | N.A |
```

**规则**：中国地区使用`N.A`（用点号），不是`N/A`（用斜杠）

### 错误3：表头格式

**S1.2表头**（正确）：
```markdown
| Perspective | 宁德时代新能源科技股份有限公司2024年年度报告 | 宁德时代新能源科技股份有限公司2023年年度报告 |
```

**规则**：
- 必须使用完整公司名称
- 格式：`公司全称+年份+年度报告`
- 不能简写为"2024 Report"
