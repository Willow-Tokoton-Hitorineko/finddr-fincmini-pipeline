### 币种和单位处理

```python
    "GBP": "GBP",
    "£": "GBP",
    "EUR": "EUR",
    "€": "EUR"

```

#### Multiplier判断
```python
def determine_multiplier_english(value, currency):
    """
    英文年报Multiplier判断
    """
    if currency in ["USD", "GBP", "EUR"]:
        # 欧美货币：优先Millions
        if value >= 1_000_000:
            return "Millions", round(value / 1_000_000, 2)
        elif value >= 1_000:
            return "Thousands", round(value / 1_000, 2)
        else:
            return "Ones", value
    
    elif currency in ["SGD", "HKD"]:
        # 亚洲发达地区：类似USD处理
        if value >= 1_000_000:
            return "Millions", round(value / 1_000_000, 2)
        else:
            return "Thousands", round(value / 1_000, 2)
    
    else:
        # 其他货币：保守使用Thousands
        return "Thousands", round(value / 1_000, 2)
```

### S3 Business Analysis
```
S3.1 Financial Analysis:
- Revenue Dynamics: 收入增长、产品结构、地区分布
- Operating Efficiency: 运营效率、成本控制、利润率
- External Impact: 外部影响、汇率、监管环境

S3.2 Profitability Analysis:
- 盈利能力分析，双年份对比

S3.3 Business Model Analysis:
- Business Model: 商业模式、盈利来源
- Market Position: 市场地位、竞争优势
```

### S4 Risk Assessment
```
四类风险识别:
- Market Risk: 市场风险（汇率、利率、商品价格）
- Operational Risk: 运营风险（供应链、人员、技术）
- Financial Risk: 财务风险（流动性、信用、杠杆）
- Compliance Risk: 合规风险（监管、法律、环保）
```

### S5 Corporate Governance
```
S5.1 Board Composition:
- 董事会构成，注意英文职位翻译
- Chairman/CEO/CFO/Independent Directors
- 薪酬信息提取

S5.2 Internal Controls:
- Risk Assessment: 风险评估
- Control Activities: 控制活动
- Monitoring: 监督机制
- Weaknesses: 识别缺陷
- Improvements: 改进措施
- Effectiveness: 有效性评价
```

### S6 Future Outlook
```
S6.1 Strategic Direction:
- M&A Activities: 并购活动
- Technology Advancement: 技术进步
- Organizational Restructuring: 组织重构

S6.2 Challenges:
- Economic Environment: 经济环境
- Competitive Landscape: 竞争格局

S6.3 Innovation Plans:
- R&D Investments: 研发投资
```

## 🔍 特殊注意事项

### 会计准则差异
```
IFRS vs 中国会计准则:
- 科目名称可能不同
- 分类标准可能有差异
- 披露要求可能不同
- 需要理解对应关系
```

### 文化差异处理
```
表述风格差异:
- 英文年报通常更直接
- 风险披露更详细
- 前瞻性表述更谨慎
- 需要适当调整分析角度
```

### 数据验证
```
额外验证点:
- 汇率换算是否合理
- 同一数据在不同币种表述的一致性
- 合并范围是否明确
- 分部信息是否完整
```
