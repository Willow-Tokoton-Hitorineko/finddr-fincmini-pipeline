```
  - 禁止：自行提炼或推断（Accuracy评分会判错）
```

### S2失分64分（得53.0/117，最严重！）

#### 🔴 致命错误1：Multiplier标注错误（-25到-30分）

**问题**：
- 你的五粮液报告全部标注`Units`（单位）
- 正确应标注`Ones`（个位，因为数值如89,175,178,323是完整数字）

**样本集标准**：
- 英伟达60,922用`Millions`（百万）
- 宁德时代362,012,554用`Thousands`（千）
- 五粮液89,175,178,323应用`Ones`（个位）

**财小析优化规则**：
```python
def determine_multiplier(value):
    if value >= 1_000_000_000:  # 超过10亿
        return "Ones", value  # 保留原值，标注Ones
    elif value >= 1_000_000:   # 100万-10亿
        return "Thousands", value // 1000
    else:
        return "Ones", value

# 五粮液Revenue: 89,175,178,323
# → 正确："Ones", 89,175,178,323
# → 错误："Units"（无此选项）
```

#### 🔴 致命错误2：Net Profit口径错误（-15到-20分）

**问题**：
- 你用了"归属于母公司股东的净利润"：31,853,173千元
- 正确应用"合并净利润"：33,193,460千元
- 差异：1,340,287千元（4.21%）

**验证依据**：宁德时代sample003官方标答使用合并净利润

**财小析优化规则**：
```python
# ✅ 正确提取
net_profit = grep("合并利润表", "五、净利润")
# 位置：合并利润表中"按经营持续性分类"上方

# ❌ 错误提取
net_profit = grep("归属于母公司股东的净利润")  # 仅归母，不含少数股东
```

#### 🔴 致命错误3：Shareholders' Equity口径错误（-8到-12分）

**问题**：
- 口径混用：Net Profit用归母，Shareholders' Equity用合并
- 导致ROE等指标计算逻辑错误

**财小析优化规则**：
```python
# 口径一致性检查
if net_profit == "合并净利润":
    shareholders_equity = "所有者权益合计"  # 必须同口径
else:
    shareholders_equity = "归属于母公司所有者权益"

# 五粮液修正：
# Net Profit: 33,193,460千元（合并）
# Shareholders' Equity: 136,394,794千元（合并）
# ✓ 口径一致
```

#### 🔴 致命错误4：财务指标格式错误（-10到-15分）

**问题**：
- 你用倍数格式：ROE = 2.47x
- 样本集标准：ROE = 24.70%（百分比）

**财小析优化规则**：
```python
# 全部财务指标用百分比格式
ratios = {
    "Current Ratio": f"{value * 100:.2f}%",     # 89.73%
    "ROE": f"{value * 100:.2f}%",               # 24.70%
    "Gross Margin": f"{value * 100:.2f}%",     # 72.71%
}
# 禁止：倍数格式（2.47x）
```
