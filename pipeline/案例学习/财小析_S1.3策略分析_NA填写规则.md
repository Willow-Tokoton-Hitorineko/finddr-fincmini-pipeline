## 🔍 评分机制深度解析

### Accuracy评分原理
```
Accuracy Score = min(Alignment Score, Coverage Score)

其中:
- Alignment Score: 检查是否有虚构/矛盾信息
- Coverage Score: 检查是否覆盖关键信息
```

### S1.3评分逻辑
```python
def evaluate_s13_accuracy(content, annual_report):
    """
    S1.3 Accuracy评分逻辑
    """
    if content == "N/A":
        # N/A被认为是诚实的表述
        alignment_score = 1.0
        coverage_score = 0.8  # 略低但可接受
        return min(alignment_score, coverage_score)  # 0.8
    
    elif is_explicit_in_report(content, annual_report):
        # 原文摘录，完全准确
        alignment_score = 1.0
        coverage_score = 1.0
        return min(alignment_score, coverage_score)  # 1.0
    
    else:
        # 自行提炼，被判为虚构
        alignment_score = 0.3  # 严重扣分
        coverage_score = 0.7
        return min(alignment_score, coverage_score)  # 0.3
```

### 为什么自行提炼会扣分？
1. **AI无法验证真实性**: 评分系统无法确认提炼内容是否准确反映公司真实意图
2. **主观性过强**: 不同人对同一年报可能提炼出不同的Mission/Vision
3. **偏离原文**: 提炼过程中可能添加年报中没有的概念或表述

## 📋 严格判断标准

### ✅ 可以填原文的情况

**明确标题披露**:
```
年报中有以下明确章节标题:
- "公司使命" / "企业使命" / "Mission Statement"
- "公司愿景" / "企业愿景" / "Vision Statement"  
- "核心价值观" / "企业价值观" / "Core Values"
```

**明确标识表述**:
```
年报中有以下明确表述:
- "我们的使命是..."
- "公司使命为..."
- "我们的愿景是..."
- "公司愿景为..."
- "我们的核心价值观是..."
```

**董事长致辞明确表述**:
```
董事长致辞中有明确、完整的表述:
- 使用"使命"、"愿景"、"价值观"等关键词
- 表述完整、具体，不是泛泛而谈
- 长度超过20字，有实质内容
```

### ❌ 必须填N/A的情况

**无明确标题**:
```
年报中没有专门的Mission/Vision章节
仅在战略规划、发展目标等章节提及相关内容
```

**模糊表述**:
```
年报中只有模糊的表述:
- "致力于成为..."（目标，非使命）
- "坚持以...为导向"（原则，非价值观）
- "努力实现..."（目标，非愿景）
```

**需要推断的内容**:
```
需要从多个段落综合推断才能得出
需要对年报内容进行总结或提炼
需要添加年报中没有的词汇或概念
```

## 🛠️ 实施规则

### Pipeline 2.2严格规则
```python
def extract_s13_strict():
    """
    S1.3极严格提取规则
    """
    # 第一优先级: 明确标题章节
    explicit_sections = [
        "企业使命", "公司使命", "Mission Statement",
        "企业愿景", "公司愿景", "Vision Statement", 
        "核心价值观", "企业价值观", "Core Values"
    ]
    
    for section in explicit_sections:
        content = grep(section, context_lines=3)
        if content and is_complete_statement(content):
            return clean_extract(content)
    
    # 第二优先级: 董事长致辞明确表述
    chairman_content = grep("董事长致辞|Chairman.*Message")
    mission_patterns = [
        r"我们的使命是(.{20,})",
        r"公司使命为(.{20,})",
        r"我们的愿景是(.{20,})",
        r"我们的核心价值观是(.{20,})"
    ]
    
    for pattern in mission_patterns:
        match = re.search(pattern, chairman_content)
        if match and is_explicit_statement(match.group(1)):
            return match.group(1).strip()
    
    # 否则严格填N/A
    return "N/A"

def is_explicit_statement(text):
    """
    判断是否为明确表述
    """
    # 长度检查
    if len(text) < 20:
        return False
    
    # 关键词检查
    vague_keywords = ["致力于", "努力", "坚持", "以...为导向"]
    if any(keyword in text for keyword in vague_keywords):
        return False
    
    # 完整性检查
    if text.endswith("...") or "等" in text:
        return False
    
    return True
```

## 🎯 实战建议

### 执行原则
1. **宁可保守，不可冒险**: N/A总比错误提炼好
2. **严格标准，统一执行**: 避免主观判断差异
3. **原文优先，禁止改写**: 有明确披露时必须用原文

### 常见误区
```
❌ 错误做法:
- 从多个段落综合提炼
- 对年报内容进行总结
- 添加年报中没有的词汇
- 将目标当作使命表述

✅ 正确做法:
- 只提取明确标识的原文
- 无明确披露时坚决填N/A
- 保持原文完整性
- 区分使命、愿景、目标的差异
```
