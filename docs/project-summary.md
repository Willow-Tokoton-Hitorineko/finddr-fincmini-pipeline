# 项目摘要 · FinCMini Agent（财小析）

FINDDR 金融文本分析赛事 · 团体全球 **第 12 名**  
系统定位：**规则库 + LLM 辅助 + 人工 QA** 的财务年报结构化 Agent 工作流

## 任务

从 8 个地区上市公司年报生成标准分析报告（Section 1–6），格式以官方 sample001–008 为准。

## 核心产出

| 类别 | 数量 | 说明 |
|------|------|------|
| 地区规范 | 8 份 | 逆向 sample + 年报对照，每份约 1.5–3 万字量级 |
| Pipeline 文档 | 39+ | 入口见 `pipeline/README_3.6.md` |
| 测试集输出 | 7 | test025–032 范围内 7 案（见 `outputs/test/`，不含 test030） |
| 验证集样例 | 9 | 部分归档于 `outputs/validation/` |

## 方法要点

1. **逆向工程**：无细则手册时，逐字段对照 sample 与年报，还原取数路径与格式铁律（如中国负数 `\-`、英国 S3.1 无括号、印尼 Multiplier 换算等）。
2. **质量门禁**：数据仅来自年报；会计恒等式必验；12 项财务指标逐项复核；格式 100% 对齐地区规范。
3. **多地区对照表**：中/澳/英等差异集中维护，避免 8 套规则混用。
