## 系统概述

本系统基于 [DeepEval SummarizationMetric](https://deepeval.com/docs/metrics-summarization#how-is-it-calculated) 实现，用于评估年报分析的质量。

### 核心原理

评分基于两个维度：
- **对齐分数 (Alignment Score)**: 评估是否存在虚构或矛盾信息（0-1）
- **覆盖率分数 (Coverage Score)**: 评估是否覆盖原文关键信息（0-1）
- **最终分数**: `min(对齐分数, 覆盖率分数)`

### 评分标准

| 分数范围 | 质量等级 | 说明 |
|---------|---------|------|
| 0.9 - 1.0 | 卓越 | 近乎完美，准确全面 |
| 0.7 - 0.9 | 优秀 | 质量很好，略有瑕疵 |
| 0.5 - 0.7 | 良好 | 基本满足要求 |
| 0.3 - 0.5 | 一般 | 部分内容缺失或不准确 |
| 0.0 - 0.3 | 较差 | 需要大幅改进 |

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置API密钥

创建 `config.py` 文件（从 `config_example.py` 复制）：

```python
# config.py
OPENAI_API_KEY = "your_openai_api_key_here"
DEFAULT_MODEL = "gpt-4"
DEFAULT_THRESHOLD = 0.5
```

或者设置环境变量：

```bash
export OPENAI_API_KEY="your_openai_api_key_here"
```

### 3. 运行评估

#### 方式一：快速评估（最简单）

```bash
python quick_evaluate.py 原始年报.md 生成报告.md
```

#### 方式二：章节详细评估

```bash
python batch_evaluate.py 原始年报.md 生成报告.md 报告名称
```

#### 方式三：Python代码调用

```python
from quick_evaluate import quick_evaluate

result = quick_evaluate(
    original_report_path="原始年报.md",
    generated_report_path="生成报告.md",
    model="gpt-4",
    threshold=0.5
)

print(f"分数: {result['overall_score']:.3f}")
```

## 使用场景

### 场景1: 快速评估单个报告

**需求**: 快速检查一份生成的年报分析质量

```bash
python quick_evaluate.py \
  ../中国移动2024年年报.md \
  600941_Analysis(2).md \
  gpt-4 \
  0.5
```

**输出**:
- 总体分数
- 对齐分数
- 覆盖率分数
- 评估原因
- JSON结果文件

---

### 场景2: 详细评估所有章节

**需求**: 了解每个章节的评分情况

```bash
python batch_evaluate.py \
  ../中国移动2024年年报.md \
  600941_Analysis(2).md \
  中国移动2024
```

**输出**:
- 每个章节的详细分数
- 章节通过情况
- CSV和JSON结果文件

---

### 场景3: 批量评估多个报告

**需求**: 对比多份报告的质量

```python
from batch_evaluate import batch_evaluate_reports

report_pairs = [
    {
        "name": "中国移动2024",
        "original": "中国移动2024年年报.md",
        "generated": "600941_Analysis_2024.md"
    },
    {
        "name": "中国移动2023",
        "original": "中国移动2023年年报.md",
        "generated": "600941_Analysis_2023.md"
    }
]

results = batch_evaluate_reports(
    report_pairs=report_pairs,
    model="gpt-4",
    threshold=0.5,
    output_dir="comparison_results"
)
```

**输出**:
- 所有报告的对比表格
- 汇总CSV和JSON文件

### 场景4: 自定义评估问题

**需求**: 使用特定的评估标准

```python
from quick_evaluate import evaluate_with_custom_questions

custom_questions = [
    "分析是否包含2023-2024年的收入增长率?",
    "是否准确反映了毛利率的变化?",

    generated_report_path="生成报告.md",

)
```

### 场景5: 集成到CI/CD

**需求**: 自动化评估，确保质量

```bash
#!/bin/bash
# evaluate.sh

# 评估生成的报告
python quick_evaluate.py \
  data/original_report.md \
  output/generated_report.md \
  gpt-4 \
  0.6 \
  > evaluation.log

# 检查是否通过
SCORE=$(python -c "import json; print(json.load(open('quick_evaluation_result.json'))['overall_score'])")

if (( $(echo "$SCORE >= 0.6" | bc -l) )); then
    echo "✓ 评估通过: $SCORE"
    exit 0
else
    echo "✗ 评估未通过: $SCORE"
    exit 1
fi
```

## 常见问题

### Q1: 评分太低，如何提高？

**对齐分数低**:
- 检查是否添加了原文没有的信息
- 确保所有陈述都有原文依据
- 避免过度解读或推断

**覆盖率分数低**:
- 检查是否遗漏了关键信息
- 确保覆盖所有重要数据点
- 增加分析的全面性

### Q2: 如何选择评估模型？

| 模型 | 速度 | 成本 | 准确度 | 推荐场景 |
|-----|------|------|--------|---------|
| gpt-4 | 慢 | 高 | 最高 | 最终评估、重要报告 |
| gpt-4-turbo | 中 | 中 | 高 | 日常评估 |
| gpt-3.5-turbo | 快 | 低 | 中 | 快速检查、开发测试 |

### Q3: 评估速度太慢怎么办？

**优化方法**:
1. 使用更快的模型（如 gpt-3.5-turbo）
2. 减少评估问题数量（参数 `n`）
3. 限制提取的真实信息数量（`truths_extraction_limit`）
4. 启用异步模式（默认已启用）

```python
metric = SummarizationMetric(
    model="gpt-3.5-turbo",  # 更快的模型
    n=5,  # 减少问题数量
    truths_extraction_limit=20,  # 限制真实信息
    async_mode=True  # 启用异步
)
```

### Q4: 是否需要提供评估问题？

**不是必需的**。系统会自动生成评估问题。

**建议**:
- **初次使用**: 使用自动生成（快速开始）
- **特定需求**: 提供自定义问题（更精准）
- **标准化评估**: 使用预定义问题（一致性）

### Q5: 如何理解评估原因？

评估原因 (reason) 会解释：
- 哪些内容做得好
- 哪些内容有问题
- 具体的改进建议

示例：
```
"总结准确反映了收入增长和毛利率改善的趋势，但在数字化转型收入占比的
具体数据上略有不足，建议补充31.3%这一关键指标。"
```

### Q6: 评估结果如何导出？

所有评估都会自动生成JSON文件：

```python
# 读取结果
import json

with open('evaluation_result.json', 'r', encoding='utf-8') as f:
    result = json.load(f)

# 导出为Excel
import pandas as pd

df = pd.DataFrame([result])
df.to_excel('result.xlsx', index=False)
```

### Q7: 可以评估非中文报告吗？

**可以**。DeepEval支持多语言评估。

```python
# 英文报告评估
result = quick_evaluate(
    original_report_path="annual_report_en.md",
    generated_report_path="analysis_en.md",
    model="gpt-4"
)
```

### Q8: API调用失败怎么办？

**常见原因**:
1. API密钥未设置或错误
2. 网络连接问题
3. API额度不足
4. 请求超时

**解决方法**:
```python
# 检查API密钥
import os
print(os.getenv("OPENAI_API_KEY"))

# 设置超时和重试
from deepeval.metrics import SummarizationMetric

metric = SummarizationMetric(
    model="gpt-4",
    timeout=120,  # 增加超时时间
    max_retries=3  # 设置重试次数
)
```
